# STYLE.md

## Commit Message Style

Use this format:

`[ISSUE_NUMBER (if assigned)] {System} // {Desc} (Tags: TAG1, TAG2)`

Examples:

- `[123] {System} // Add issue-triggered demo workflow (Tags: MVP, UNTESTED)`
- `[NO-ISSUE] {System} // Update docs for dev container setup (Tags: WIP)`

## Branch Naming Style

Use this format:

`vfp/agent/{branch_name}`

Examples:

- `vfp/agent/issue-demo-workflow`
- `vfp/agent/docs-style-note`
